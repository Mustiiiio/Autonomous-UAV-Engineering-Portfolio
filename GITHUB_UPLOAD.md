# Upload this folder as one GitHub repository

1. Create a new empty GitHub repository with the name suggested in the bundle `START_HERE.md`.
2. Upload all files **inside this repository folder** so that `README.md` appears at the repository root.
3. Check that the README figures display correctly; file paths are case-sensitive.
4. Check contributor permission for team project figures and remove personal identifying details before public publication.
5. Keep large MP4 videos in GitHub Releases or YouTube (Unlisted), then paste real links into the READMEs.
6. Add original MATLAB/Simulink/PX4/Gazebo code and measured flight/research data only after verification.

The master bundle's `PRIVATE_Source_Reports_DO_NOT_UPLOAD_TO_GITHUB` folder is **not** part of this repository.
